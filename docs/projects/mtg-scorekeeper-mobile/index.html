MTG Scorekeeper Mobile

The native follow-up to my MTG tracker, rebuilt for phones and tablets.

Role
Designer and developer
Status
In development
Updated
Aug 2026
  • React Native
  • Expo
  • JavaScript

After using the web tracker, I wanted to see what the same idea would feel like as a proper mobile app. I am rebuilding it with React Native and Expo from the ground up.

The app already has game setup, player panels, Commander search, themes, and settings. The most interesting work has been pulling the game rules into reusable logic while giving phones and tablets an interface that feels natural on each screen.

It is still in development. Right now I am tightening the game flow and deciding which ideas from the web version deserve to come along.
