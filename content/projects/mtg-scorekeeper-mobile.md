The mobile evolution of my Magic: The Gathering scorekeeper, built with React Native and Expo. It brings the game setup, player panels, commander search, themes, settings, and reusable game engine into an app designed specifically for phones and tablets.

This project is currently in development as I turn the ideas tested in the web app into a focused native experience.
